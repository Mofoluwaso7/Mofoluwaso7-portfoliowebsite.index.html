# Mofoluwaso's Website

This is a personal website about Mofoluwaso and their web development projects. It was made with HTML, CSS, and JavaScript.

## View the website

[Open Mofoluwaso's live website](https://mofoluwaso7.github.io/Mofoluwaso7-portfoliowebsite.index.html/)

## What is on the website?

- An About section
- A Projects section with pictures and a video
- A Contact section
- A contact form that opens an email draft when you submit it

## Open the website

Find `index.html` in the project folder and double-click it. It will open in your web browser.

You can also open the project folder in a terminal and start a local web server:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000/` in your browser.

Some pictures and fonts come from the internet, so they may not appear when you are offline. The video is saved in this project folder.

## Project files

- `index.html` — the words and sections on the website
- `stylesheet/portfolio.css` — the website's colors, layout, and appearance
- `JS/one_page_website.js` — the code that makes some parts of the website interactive
- `Videos/animal_slideshow.mp4` — the video shown in the Projects section

## Make changes

- To change the words on the page, edit `index.html`.
- To change the colors or layout, edit `stylesheet/portfolio.css`.
- To change the contact information, edit the page and `JS/one_page_website.js`.
- To use a different video, replace `Videos/animal_slideshow.mp4`.
